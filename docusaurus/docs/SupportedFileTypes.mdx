## Supported file types

You can import and work with these data formats:

- **Tabular data**
  - Excel (xls, xlsm, xlsb, xlsx)
  - csv
  - numbers
  - ods
  - parquet
- **Text** (txt, md, markdown, pdf)
- **Code** (json, js, html, xml)
- **Images** (jpg, png)
- **Video** (mp4 and other formats your browser supports)
- **Databases** (sqlite, sqlite3, db, db3, s3db, sl3)

:::info
Video and database files are, due to file size, only stored locally in your browser.
:::
