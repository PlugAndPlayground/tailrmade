# Use the canvas

The infinite canvas is your main working area. You can quickly zoom in and out, and pan around to explore different parts of your application logic.

![Canvas](/img/screenshots/example-graph.png)

## Navigate the canvas

We try to auto detect if you are using a mouse or touch device, but you can always manually switch:

### Switch gesture mode

- **Gesture mode**: Right-click the canvas to set the gesture mode (Mouse/Trackpad)

![Gesture Mode](/img/screenshots/gesture-mode.png)

### Using the mouse

- **Zoom**: Mouse wheel
- **Pan**: Right click + drag

### Using the trackpad

- **Zoom**:
  - Pinch gesture
  - OR `Ctrl` + 2 finger movement
- **Pan**:
  - 2 finger movement
  - OR right click + drag

### Using keyboard shortcuts

- **Zoom in**: `Ctrl` + `=` key
- **Zoom out**: `Ctrl` + `-` key
- **Reset Zoom**: `Ctrl` + `0` key

Learn more about [Keyboard Shortcuts](/help/docs/keyboard-shortcuts)
