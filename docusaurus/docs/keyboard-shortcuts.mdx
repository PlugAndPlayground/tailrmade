## Move Between Nodes

Select a node, then move with the arrow keys. Each move pulses the node you land on.

| Action                                      | Windows/Linux                | macOS                           |
| ------------------------------------------- | ---------------------------- | ------------------------------- |
| Go to the nearest node in that direction    | `Arrow keys`                 | `Arrow keys`                    |
| Follow the wires upstream/downstream        | `Alt+Arrow left/right`       | `Option+Arrow left/right`       |
| Switch to the other nodes on that wire step | `Alt+Arrow up/down`          | `Option+Arrow up/down`          |
| Back/forward through your wire jumps        | `Alt+Shift+Arrow left/right` | `Option+Shift+Arrow left/right` |
| Go from a macro call to the macro           | `Enter`                      | `Enter`                         |
| Go from a macro back to where it was called | `Shift+Enter`                | `Shift+Enter`                   |

The arrow keys alone ignore wires and go to the nearest node on the canvas. With `Alt`/`Option` they follow wires: upstream starts at the node's top-most input and `Alt+Arrow down` goes through the others; downstream starts at the top-most target. The node you came from is outlined, with rings on its sockets: the wire you took is highlighted and the other wires of that step are shown faintly. Going back the way you came returns to the node you came from. Clicking a socket also lists the nodes at the other end of its wires.

## Node Management

| Action               | Windows/Linux                   | macOS                        |
| -------------------- | ------------------------------- | ---------------------------- |
| Search nodes         | `Ctrl+F` or double-click canvas | `⌘+F` or double-click canvas |
| Delete node(s)       | `Delete` or `Backspace`         | `Delete` or `Backspace`      |
| Duplicate node(s)    | `Ctrl+D` or `Alt+Drag`          | `⌘+D` or `Option+Drag`       |
| Cut node(s)          | `Ctrl+X`                        | `⌘+X`                        |
| Copy node(s)         | `Ctrl+C`                        | `⌘+C`                        |
| Paste node(s)        | `Ctrl+V`                        | `⌘+V`                        |
| Extract to macro     | `Shift+M`                       | `⌘+M`                        |
| Combine to array     | `Shift+A`                       | `⌘+A`                        |
| Combine draw nodes   | `Shift+C`                       | `⌘+C`                        |
| Combine into UI page | `Shift+U`                       | `⌘+U`                        |
| Auto-align node(s)   | `A`                             | `A`                          |
| Group node(s)        | `Ctrl+G`                        | `⌘+G`                        |
| Ungroup              | `Ctrl+Shift+G`                  | `⌘+Shift+G`                  |
| Remove from group    | `Ctrl+Alt+G`                    | `⌘+Option+G`                 |

:::info
Auto-align only works when one or more nodes are selected.
:::
