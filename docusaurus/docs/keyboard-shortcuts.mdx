# Keyboard Shortcuts

Master Tailrmade with these keyboard shortcuts.

## General Shortcuts

| Action                    | Windows/Linux              | macOS                |
| ------------------------- | -------------------------- | -------------------- |
| Open app                  | `Ctrl+O`                   | `⌘+O`                |
| Edit app details          | `Ctrl+E`                   | `⌘+E`                |
| Save                      | `Ctrl+S`                   | `⌘+S`                |
| Save as                   | `Ctrl+Shift+S`             | `⌘+Shift+S`          |
| Undo                      | `Ctrl+Z`                   | `⌘+Z`                |
| Redo                      | `Ctrl+Y` or `Ctrl+Shift+Z` | `⌘+Y` or `⌘+Shift+Z` |
| Open left side menu       | `1`                        | `1`                  |
| Open user interface       | `2`                        | `2`                  |
| Maximise user interface   | `M`                        | `M`                  |
| Inspector: Graph          | `3`                        | `3`                  |
| Inspector: User interface | `4`                        | `4`                  |
| Inspector: App            | `5`                        | `5`                  |

:::info
Undo/Redo history for the canvas is separate from the one in the user interface editor.
:::

## Canvas Navigation

| Action          | Windows/Linux                               | macOS                                       |
| --------------- | ------------------------------------------- | ------------------------------------------- |
| Pan (mouse)     | Middle/Right click + drag                   | Middle/Right click + drag                   |
| Pan (trackpad)  | Two-finger drag                             | Two-finger drag                             |
| Zoom (mouse)    | Mouse wheel                                 | Mouse wheel                                 |
| Zoom (trackpad) | Two-finger pinch or `Ctrl`+ Two-finger drag | Two-finger pinch or `Ctrl`+ Two-finger drag |
| Zoom in         | `Ctrl+=`                                    | `⌘+=`                                       |
| Zoom out        | `Ctrl+-`                                    | `⌘+-`                                       |
| Zoom 100%       | `Ctrl+0`                                    | `⌘+0`                                       |
| Zoom to fit all | `Shift+1`                                   | `Shift+1`                                   |
| Zoom selection  | `Shift+2`                                   | `Shift+2`                                   |

## Node Management

| Action                  | Windows/Linux                   | macOS                        |
| ----------------------- | ------------------------------- | ---------------------------- |
| Search nodes            | `Ctrl+F` or double-click canvas | `⌘+F` or double-click canvas |
| Delete node(s)          | `Delete` or `Backspace`         | `Delete` or `Backspace`      |
| Duplicate node(s)       | `Ctrl+D` or `Alt+Drag`          | `⌘+D` or `Option+Drag`       |
| Cut node(s)             | `Ctrl+X`                        | `⌘+X`                        |
| Copy node(s)            | `Ctrl+C`                        | `⌘+C`                        |
| Paste node(s)           | `Ctrl+V`                        | `⌘+V`                        |
| Extract to macro        | `Shift+M`                       | `⌘+M`                        |
| Combine to array        | `Shift+A`                       | `⌘+A`                        |
| Combine draw nodes      | `Shift+C`                       | `⌘+C`                        |
| Combine into UI surface | `Shift+U`                       | `⌘+U`                        |
| Auto-align node(s)      | `A`                             | `A`                          |

:::info
Auto-align only works when one or more nodes are selected.
:::

## Selection

| Action             | Windows/Linux                         | macOS                                 |
| ------------------ | ------------------------------------- | ------------------------------------- |
| Select All         | `Ctrl+A`                              | `⌘+A`                                 |
| Select None        | `Escape`                              | `Escape`                              |
| Multiple Selection | `Shift` + click or drag selection box | `Shift` + click or drag selection box |
| Toggle Selection   | `Shift` + click                       | `Shift` + click                       |

## Connections

| Action             | Windows/Linux                                  | macOS                                          |
| ------------------ | ---------------------------------------------- | ---------------------------------------------- |
| Create Connection  | Drag from output to input socket or vice versa | Drag from output to input socket or vice versa |
| Delete Connection  | Drag from output and release                   | Drag from output and release                   |
| Reroute Connection | Drag from output or `Ctrl`drag from input      | Drag from output or `Ctrl`drag from input      |

## User interface editor

| Action                                                  | Windows/Linux                                | macOS                                        |
| ------------------------------------------------------- | -------------------------------------------- | -------------------------------------------- |
| Toggle user interface                                   | `2`                                          | `2`                                          |
| Move widget selection                                   | `Arrow up/down`                              | `Arrow up/down`                              |
| Move selection one level up/down (enter/exit container) | `Enter/Shift+Enter`                          | `Enter/Shift+Enter`                          |
| Move selection                                          | `Alt + Arrow up/down`                        | `Option + Arrow up/down`                     |
| Remove widget                                           | `Delete` or `Backspace` with widget selected | `Delete` or `Backspace` with widget selected |
