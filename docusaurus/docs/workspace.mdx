# Interface Overview

Learn the key elements of the Tailrmade interface.

## Workspace Layout

![Tailrmade Interface](/img/screenshots/interface-overview.png)

The Tailrmade interface consists of these main areas:

- Left side bar/menu (Press `1`)
- User interface/User interface editor (Press `2`) - [How to build user interfaces](/help/docs/build-user-interface)
- Canvas area (main working area) - [How to use the canvas](/help/docs/canvas)
- Inspector (Press `3`) - [How to use the inspector](/help/docs/inspector)

## Left side bar/menu

The left side bar provides access:

- Show/Hide the left side bar
- Login or view your account
- Open the apps list to manage your apps
- Open the AI assistant
- Access the documentation
- Share your app
- Create a new app

### To open the apps list

- Press `1` to show/hide the apps list
- OR click the apps list icon in the top left corner

![Open apps list](/img/screenshots/open-appslist-icon.png)
