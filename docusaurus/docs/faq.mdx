# FAQ

Frequently asked questions about _tailrmade_.

## General Questions

### What is _tailrmade_?

_tailrmade_ helps you build web apps visually in your browser. Turn your ideas into interactive applications without signup required. It's a visual-first development platform where you can build naturally by connecting components in a reactive workspace, see changes instantly, and access the code layer whenever you need more customization. _tailrmade_ handles multiple data types (text, images, audio, video) in one unified environment.

### Is _tailrmade_ free to use?

Yes. However, there are premium features and higher usage limits available with a paid subscription. Please contact us at [support@tailrmade.app](mailto:support@tailrmade.app) for details.

### Do I need an account to use _tailrmade_?

No. However, creating an account allows you to

- share your apps via link with others
- access your work from any device
- use our AI assistant

Learn more about how to [Sign in to tailrmade](/help/docs/signin)

### Do I need to install anything to use _tailrmade_?

No, _tailrmade_ runs in modern web browsers. You don't need to install any software to get started. Simply visit [tailrmade.app](https://tailrmade.app)

### What browsers are supported?

_tailrmade_ works best on the following desktop browsers:

- Google Chrome (recommended)
- Microsoft Edge
- Firefox
- Safari

:::info
Mobile browsers are supported but the experience is optimized for desktop use.
:::

### Do I need to know how to code?

No programming knowledge is required to get started with _tailrmade_. The visual interface allows you to build applications by connecting nodes together. However, for more advanced functionality, basic JavaScript knowledge can be helpful when creating custom nodes.

## Working with Apps

### How do I save my work?

1. Press `Ctrl/⌘+S` or right-click on the canvas and select "Save"

### How do I share my app with others?

1. Click on the "Share" button in the top left

Learn more about how to [Share your app](/help/docs/share-app)

### Can I export my app?

Yes. Learn more about how to [Download your app](/help/docs/share-app#download-the-app)

### How do I import an app?

Yes.

1. Drag and drop a `.tmapp` file onto the canvas (legacy `.ppgraph` files are also supported)
   - OR right-click on the canvas and select "Load from file"

## Features and Functionality

### What kind of data can I import?

_tailrmade_ supports a variety of data formats.

Learn more about our [Supported file types](/help/docs/importing-data#supported-file-types)

### Can I connect to external APIs?

Yes, you can use the HTTP node to connect to external APIs. This allows you to fetch data, send data, and integrate with other services.

### Is there a limit to how complex my app can be?

While there's no hard limit on the number of nodes you can use, performance may be affected by very complex apps. For optimal performance, consider:

- Breaking complex functionality into macros
- Using custom nodes for computation-heavy operations

### Can I use _tailrmade_ offline?

Currently, _tailrmade_ requires an internet connection to function fully. However, once loaded, many operations can continue to work during brief connectivity interruptions.

## Technical Questions

### Can I embed _tailrmade_ apps in other websites?

Yes, you can embed apps using an iframe. Learn more about how to [Embed your app in a website](/help/docs/share-app#embed-in-website)

### Where is my data stored?

Your apps and imported data are stored securely in the cloud. _tailrmade_ uses industry-standard security practices to protect your data. For details, see our Privacy Policy.

### Is there a size limit for apps in the cloud?

Yes. See our [Current account limits](/help/docs/signin#current-account-limits)

### Can I use custom JavaScript libraries?

Yes, you can load npm packages via the `Load NPM package` node.
