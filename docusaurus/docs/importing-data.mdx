# Import data

We support importing data from a variety of data sources and formats.

<SupportedFileTypes />

## Importing local files

1. Drag in one or more files from your computer
2. Drop it/them onto the canvas
3. A node representing that data is automatically created

_For allowing your user to upload files in your app, use the **File Upload** widget in the user interface._

### Replacing image files

To replace an existing image file:

1. Select the image node(s) you want to replace
2. Drag in the new image file from your computer
3. Press `Shift` and drop it/them onto the canvas
4. The old image(s) will be replaced with the new one(s)

## Working with Data

Once data is imported, you can:

- **Transform** it using data operation nodes
- **Filter** using logical operations
- **Visualize** with charts, tables or custom visualizations
- **Extract** specific values or ranges
- **Combine** multiple data sources
