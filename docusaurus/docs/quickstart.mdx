# Quickstart

### Create your first app

1. Open tailrmade: Go to [tailrmade.app](https://tailrmade.app) or click [tailrmade.app/?new=true](https://tailrmade.app/?new=true) to start a blank app
2. **Import data**:
   - Drag and drop files (CSV, Excel, images) onto the canvas
   - Or use the HTTP node to fetch data from APIs
   - Learn more about how to [Import Data](/help/docs/importing-data)
3. **Add nodes**:
   - `Double click` the canvas or press `Cmd/Ctrl+F` to open the node search
   - Search for what you want to do (e.g., "number", "text", "http") and press `Enter`
   - Learn more about how to [Build the graph](/help/docs/build-graph)
4. **Connect nodes to build logic**:
   - `Click` on an output socket (right side of node)
   - Drag to an input socket (left side of another node)
   - Change parameters using the inspector on the right
   - Learn more about how to [Use the inspector](/help/docs/inspector)
5. **Create user interface**
   - Press 2 to open the panel
   - Drag widgets/nodes onto the interface area
   - Use containers to organize your layout
   - Learn more about how to [Build the user interface](/help/docs/build-user-interface)

### Open an example app

1. Open [tailrmade.app](https://tailrmade.app)
2. Press 1 or `Cmd/Ctrl+O` to open the Apps list
3. Browse the available _Example apps_
4. Select one to open and explore how it works
