## What is _tailrmade_?

_tailrmade_ is your personal app builder - create and share apps that matter to you, regardless of your skill level.

:::info Instead of AI agents, we give you agency

- **Visual Programming First** - A visual programming platform with optional AI assistance, not AI-generated walls of code. Write "real" code on demand for maximum power and flexibility
- **Understand Every Component** - Every node and connection is visible and modifiable, giving you full transparency of how your app works
- **Common Language Between You and AI** - When you do use AI assistance, it builds using the same visual nodes you work with, allowing you to understand and modify its suggestions
- **Iterate Without Regenerating** - Modify any single component without having to regenerate entire sections of code or lose your other customizations
- **Data-Oriented Architecture** - Built around visible data flows rather than code files, making complex transformations intuitive to follow and debug
- **True Ownership** - Modify any part of your application without wrestling with someone else's coding style
  :::

## Who is it for?

### For Developers

You know how to code, but want to build faster. Explore APIs, visualize data, and test ideas in real-time.

### For Creatives

You have design skills but limited coding experience. Create interactive visuals and transform different media without coding barriers.

### For Problem Solvers

You need custom solutions for your data. Connect, analyze, and visualize data from multiple sources easily.

_tailrmade_ allows you to transform raw data into beautiful, interactive visualizations by:

- Connecting to CSV, Excel, and API data sources
- Transforming data with visual filters and operations
- Creating interactive charts, tables, and visualizations
- Sharing interactive dashboards with others

## Why _tailrmade_?

:::info Key benefits

- **Visual-First Development** - Build naturally by connecting components in a reactive workspace that feels intuitive
- **Always Real-Time** - See changes instantly as you build, with immediate feedback that keeps you in the flow
- **Code When You Want** - Access the code layer whenever you need more customization
- **Multi-Modal Data** - Handle text, images, audio, and video in one unified environment
- **Browser-Based** - Work from any device with a modern browser, no downloads required
- **No Registration** - Start building immediately without creating an account
  :::
