# About

_tailrmade_ started as a side project called "Plug and Playground". The goal was to create a tool that allows anyone to build custom web apps without needing to write code. Over time, it has evolved into a powerful platform that combines visual programming with AI capabilities.

Join our journey and watch out for many more things to come...
