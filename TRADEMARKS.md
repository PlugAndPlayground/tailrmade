# Tailrmade Trademark Policy

This policy explains how the Tailrmade name, logos, product marks, domain
names, icons, screenshots, and other brand assets may be used.

The software code in this repository is licensed under the GNU Affero General
Public License v3.0 or later. That license gives broad rights to use, copy,
modify, and redistribute the code. It does not grant rights to use the
Tailrmade trademarks or branding.

## Protected Marks

The protected marks include:

- Tailrmade
- tailrmade
- tailrmade.app
- Tailrmade logos, icons, and visual brand assets
- Any confusingly similar names, logos, or branding

## Allowed Use

You may use the Tailrmade marks without separate permission when the use is
truthful, non-confusing, and limited to identifying this project, for example:

- referring to the original Tailrmade project
- linking to tailrmade.app or this repository
- describing compatibility with Tailrmade
- saying that your work is a fork of Tailrmade
- using screenshots of unmodified Tailrmade for documentation, reviews,
  tutorials, or commentary

## Modified Versions and Forks

If you distribute, host, or publicly make available a modified version or fork,
you must make it clear that it is not the official Tailrmade service unless you
have written permission.

Modified versions and forks must not:

- use Tailrmade as the product or service name
- use Tailrmade logos or icons as the main branding
- use a domain name or social account that suggests official Tailrmade status
- imply endorsement, partnership, or sponsorship by the Tailrmade project
- present themselves as the official Tailrmade service

Acceptable examples include:

- "ExampleApp, a fork of Tailrmade"
- "Compatible with Tailrmade graph files"
- "Based on Tailrmade, with modifications"

Unacceptable examples include:

- calling a fork "Tailrmade Pro" without permission
- running a hosted service branded as "Tailrmade"
- using the Tailrmade logo as the primary app icon for a fork
- registering domains such as `tailrmade-hosting.example` in a way that implies
  official status

## Official Builds

Only the Tailrmade project maintainers may describe a build, website, package,
container image, app store listing, or hosted service as official.

If you redistribute an unmodified build, you may state that it is an unmodified
copy of Tailrmade, provided that you do not imply that you operate the official
Tailrmade service.

## Permission

For permission to use the Tailrmade marks outside this policy, contact the
project maintainers.

The maintainers may update this policy to clarify acceptable trademark use.
